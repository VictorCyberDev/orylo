# Entitlement audit

Purpose: list every capability the mandate asks about, what public eGain documentation says, and what the owner must check in the trial UI. Nothing here was confirmed in a tenant, and no capability should be assumed from marketing material.

Trial status for every row is `UNVERIFIED in trial`: this session had no eGain tenant, credentials or browser access.

Method and limits (2026-11-10): the hackathon rules page was read in full. The hands-on lab page returned only its overview text and a sign-in form. eGain's help site (`ebrain.egain.com`) renders client-side, so release-note pages came back empty; only search-result excerpts and a search tool's summaries of those pages were available, and those are labelled "excerpt". Product marketing pages and the public SDK repository were read. The Firecrawl search credits ran out partway through, so some searches were run with a different search tool.

"Owner must check" means: look in the trial UI, then write what you saw in the "Observed by owner" column of your own copy.
